# Smart Campus Queue & Token Management System

An interactive full-stack web application designed to digitize campus service queues, reduce physical crowding, and streamline administrative workflows through real-time token tracking.

---

## 📌 Problem Statement

Traditional service counters across educational campuses—such as fee payments, admissions, document verification, and administrative desks—suffer from severe physical bottlenecks. Key challenges include:

- **Unnecessary Waiting Times:** Students spend hours standing in physical lines without visibility into actual processing times.
- **Administrative Congestion:** Crowded waiting areas create chaotic environments for service desk staff.
- **Lack of Live Updates:** Standard queue tools rely on periodic page refreshes or static ticket printers, leading to high server load and delayed status syncing.

---

## 💡 Solution

The **Smart Campus Queue & Token Management System** converts traditional physical queues into a seamless, transparent digital process:

- **Digital Token Generation:** Students can request digital tokens remotely for specific service counters.
- **Real-Time Synchronisation:** Built with WebSockets to stream instantaneous queue status updates across all connected devices without page refreshes.
- **Role-Based Workflows:** Tailored interfaces for Students (to track wait times and active numbers) and Counter Staff/Admins (to call, complete, or skip tokens).

---

## 🛠️ Tech Stack

- **Frontend:** React (Single Page Application, Dynamic UI)
- **Backend:** Python (REST API & WebSocket Engine)
- **Real-Time Communication:** WebSockets (Persistent, full-duplex live updates)
- **Database:** SQLite / Relational Database (3NF Normalized Data Schema)
- **Version Control:** Git & GitHub
